# Libron

The four original WOFF2 files were supplied by Anant Jain. The README artwork
uses **Libron Regular** for upright display titles and headings. The other
weights are kept here for future use.

Pillow renders the font directly into the PNG and GIF assets, so GitHub readers
do not need to install the font and GitHub does not need to load a web font.

The embedded font metadata identifies the license as the SIL Open Font License,
Version 1.1. See LICENSE.txt in this directory.
